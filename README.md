# DADA forumo grafinis prototipas

Plain PHP, HTML, CSS ir JavaScript prototipas, sukurtas pagal `dada documentation/` aplanke pateiktą specifikaciją. Duomenys laikomi `data/demo-data.php` masyvuose; duomenų bazė ir tikra autentifikacija nenaudojamos.

## Paleidimas

Nukopijuokite projektą į XAMPP `htdocs/DADA/` aplanką ir atidarykite:

`http://localhost/DADA/`

Arba lokaliai patikrai paleiskite `php -S 127.0.0.1:8080 -t .`.

Viršuje esantis **Prototipo režimas** leidžia perjungti Svečio, Naudotojo ir Administratoriaus sąsajas.
